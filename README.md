# 🚀 Treze7 Pro

Sistema ERP desenvolvido para auxiliar na gestão da loja **Treze7 Eletrônicos**, com foco na organização operacional, assistência técnica, vendas e gerenciamento de atendimentos.

---

## 📌 Sobre o Projeto

O Treze7 Pro foi criado para facilitar a rotina da loja, centralizando informações importantes em um único sistema e tornando os processos mais organizados e eficientes.

Realizei a idealização e estruturação das funcionalidades do sistema, pensando nas necessidades reais da operação da empresa.

---

## ⚙️ Funcionalidades

✅ Dashboard gerencial  
✅ Controle de vendas  
✅ Assistência técnica  
✅ Emissão de orçamentos  
✅ Cadastro de clientes  
✅ Cadastro de aparelhos  
✅ Relatórios gerenciais  
✅ Visualização/exportação em PDF  
✅ Organização operacional da loja  
✅ Integração com WhatsApp

---

## 🛠️ Tecnologias e Ferramentas

- Lovable
- GitHub
- HTML
- CSS
- JavaScript
- React
  


---

## 🎯 Objetivo

O objetivo do sistema é melhorar a organização da loja, otimizar processos internos e facilitar o gerenciamento das informações da assistência técnica e vendas.
